# Top-700-Films-on-IMDb
An interactive Power BI dashboard analyzing the 700 top-ranked films on IMDb (as of 2026) to surface trends across ratings, runtime, genre, director, and decade. 

**Watch demo here: <https://youtu.be/8frPzo0UH1M>**

Uses data from: <https://www.kaggle.com/datasets/saitejabandaruin/imdb-top-700-movies-2026-edition>
